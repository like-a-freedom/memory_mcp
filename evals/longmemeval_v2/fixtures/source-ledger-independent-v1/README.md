# Source-ledger independent controls v1

Six source-reviewed development cases authored and labels frozen before outputs for this protocol. They test conflicting and consistent repeated anchors, named scopes, role-selected anchors, opaque omitted children and clipped repeated anchors. Source labels differ from the preceding ten exposed regression cases. These are development controls, not an independent memory-treatment benefit study.

Each target appears among three unrelated source scopes; its index rotates. Exact source strings remain available; annotations never replace them. UNKNOWN means the delivered evidence cannot uniquely establish the answer, not that the action is absent. No prediction, model judge or retrieval result supplies these labels. All errors remain in the scheduled denominator.
