# Retained failed full-record quote registration

This first registration required the full raw source line including the Fact: record label. All 12 values, cited sources and abstention decisions were correct, but six actual-memory arms quoted the source proposition without that label, which extraction intentionally omits from public fact content/quote. Four sufficient-fixed-reply arms and two actual-memory false-premise arms passed the registered exact-quote condition. The first capture therefore failed 6/12 and no second capture ran. Original inputs, script, raw responses and strict results are unchanged.

This is a contract mismatch, not evidence that these six propositions were fabricated or wrongly read. The replacement source-span contract is separately tested: the exact quote must contain the whole independently registered proposition, occur in the original cited source, and occur in actually delivered content/quote of that same cited source. It permits a source record label only when actually delivered. A different source cannot donate the quote. The replacement screen uses new disjoint source texts/values and its own frozen stop rule; this failed run is not retroactively called qualified.
