# A8 preregistration: evaluator-only evidence action hint

Frozen before any model request. The entire cohort is synthetic. The run is local to native Apple Silicon and uses the provider-neutral loopback Chat Completions adapter. No LM Studio app/API and no remote model service are used; the endpoint is the already running local MLX-compatible server at `http://127.0.0.1:18767/v1`.

## Question and contrast

Does appending a bounded evaluator-only action hint to the same validated public `assemble_context` response improve an agent's final answer on ordinary support, conflicting sources, or absent evidence? The candidate and incumbent use identical seeded histories, registered memory arguments, source replies, task prompts, model alias, sampler, budgets, and memory binary. Only the candidate's fixed-read `presentation` is `evidence_action_hint`; incumbent uses the historical `current` projection. This is an evaluator experiment; it does not change product wire output.

## Frozen cohort and gates

Three independent synthetic families, one paired trial per family, six trials total. Pair order is fixed in `plan.json`: incumbent first for Opal and Helios, candidate first for Quartz. The response oracle requires exact answer value, exact cited returned source set sufficient for the task, and the preregistered clarification boolean. Every observed run remains in the denominator. Report per-arm task success, observed evidence and citation coverage, clarification match, prohibited evidence/other hard violations, trial status, tokens, tool calls, and paired wall-time deltas. Report median and range by arm; these three families are a screen, not a powered estimate. Do not calculate a significance claim or memory treatment effect.

The fixed replies were generated by a separate local public-MCP preflight with zero model requests. They contain the registered positive source for Opal, both conflicting statements for Quartz, and an empty result for Helios. The current product returns no typed `evidence_status` or reconciliation relation for the first two cases, so the candidate must fail closed to `verify_or_ask`; it cannot claim to detect a typed conflict. The preflight source event coverage, completeness, schema hash and model-request count are recorded in `preflight.json`.

## Stop and decision rules

Run exactly capture 01, both arms, all three families. Retain all failures. Stop and mark the screen NO-GO if candidate exact task success is lower than incumbent, any new prohibited-evidence/unsafe action appears, citation or clarification performance regresses on a family, or candidate increases a timeout/budget exit. A candidate-only task success with no such regression may justify freezing a disjoint follow-up screen; it does not authorize a product change. A product wire proposal requires a separate successful disjoint evaluation and compatibility review. A malformed registration, identity mismatch, nonlocal endpoint, or product/model fingerprint drift invalidates the run before capture and must not be silently retried under this plan.

## Identities and execution

`plan.json`, `tasks.json`, `fixed-read-inputs.json`, `sampling.json`, and `preflight.json` are frozen inputs. `plan.json` pins the exact memory and eval executable hashes, endpoint identity, model identifier, tool schema, all prompt/policy hashes, reader registration, corpus, oracle, sampler, feature/config profile, and budgets. `SHA256SUMS` records the frozen files. The model identity is the exact id returned by local `/v1/models`; temperature is 0.0; provider retries are outside the adapter and must be retained if reported. Each trial has one tool-call budget, three turns, 384 output tokens, 4,096 context tokens, and a 90-second wall budget.

Run from the repository root:

Two initial no-model CLI validations rejected relative memory-binary and
output-directory paths before a trial or model request. The command below uses
absolute paths; no task, reply, plan identity, or model setting changed.

```sh
cargo run --locked -p eval-harness --bin memory-eval -- run-paired-chat-completions \
  --recall-read-mode fixed-reply \
  --fixed-read-inputs evals/paired/a8-evidence-action-hint-2026-11-25/fixed-read-inputs.json \
  --plan evals/paired/a8-evidence-action-hint-2026-11-25/plan.json \
  --tasks evals/paired/a8-evidence-action-hint-2026-11-25/tasks.json \
  --model-endpoint http://127.0.0.1:18767/v1 \
  --sampling-config evals/paired/a8-evidence-action-hint-2026-11-25/sampling.json \
  --incumbent-memory-server "$PWD/target/debug/memory_mcp" \
  --candidate-memory-server "$PWD/target/debug/memory_mcp" \
  --output-directory "$PWD/evals/paired/a8-evidence-action-hint-2026-11-25/capture-01"
```
